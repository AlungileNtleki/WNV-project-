# Processed Datasets

This directory contains processed datasets generated during the WNV Lineage 2 research project.

## 1. Lineage Confirmation

- `WNV_L2_GenomeDetective_confirmed.fasta` – Sequences confirmed using Genome Detective.
- `WNV_L2_merged_confirmed.fasta` – Merged confirmed Lineage 2 sequences.

## 2. Quality Control

- `WNV_L2_Nextclade_results.csv` – Sequence classification and quality-control results.
- `WNV_L2_filtered_metadata.csv` – Metadata for filtered sequences.

## 3. Envelope Analysis

- `WNV_Envelope_Mutation_Summary.csv` – Envelope protein amino-acid substitutions.
- `WNV_Envelope_unaligned.fasta` – Unaligned envelope sequences.
- `WNV_Envelope_aligned.fasta` – Aligned envelope sequences.

These datasets support downstream analyses of WNV-L2 envelope mutations, geographic distribution and selection patterns.
